## 2026-10-25 - Python File IO in Directory Loops
**Learning:** `os.listdir()` paired with `os.path.isfile()` inside a loop causes redundant system `stat` calls which can significantly degrade performance in large directories. Additionally, `re.search()` compiling expressions inside a loop causes unnecessary overhead.
**Action:** Always precompile regexes before the loop using `re.compile()`. Use `os.scandir()` instead of `os.listdir()`, which is more performant as it fetches file attributes without an extra `stat` call. Finally, utilize Python's EAFP principle by directly trying to open the file wrapped in a `try...except OSError` block.
